To-Do List App

This is a simple To-Do List application made using HTML, CSS, and JavaScript.

I made this project to practice my basic web development skills and learn how JavaScript works with HTML and CSS.

Features
Add a new task
Mark a task as completed
Delete a task
Simple and clean design
Easy to use
Technologies Used
HTML
CSS
JavaScript
How to Run
Download or clone this project.
Open the project folder.
Open the index.html file in your browser.
Now you can start adding your tasks.
Project Structure
To-Do-App/
│
├── index.html
├── style.css
└── script.js

How It Works

You can type a task in the input box and click the Add button.

The task will be added to the list. You can mark the task as completed when you finish it. You can also delete a task when you don't need it anymore.

JavaScript is used to handle the tasks and make the application interactive.
